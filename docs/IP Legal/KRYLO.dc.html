04 — Architecture

Reasoning Architecture

A staged reasoning architecture where each layer performs a distinct analytical function under defined constraints.
COMPONENT
DEFINITION
ROLE IN PIPELINE
CI-F
Causal Inference Formation Engine
Causal Expansion System — expands an initial knowledge claim into candidate causal structures by traversing the knowledge store and identifying evidence-backed relationships.
Produces candidate causal graphs for validation.
CI-R
Causal Inference Reality Validator
Constitutional Validation Gate — performs binary validation of candidate causal structures against three immutable constraints: edge legality, temporal legality, and evidence-anchor coverage.
Rejects invalid branches before scoring.
RBCS
Reality Branch Convergence Score
Branch Scoring Engine — scores only branches admitted by CI-R using a weighted geometric model across five independent factors: temporal advantage, divergence, cross-domain coupling, amplification, and volatility.
Produces ranked candidate branches.
LFOS
Lifecycle Forecasting & Outcome Simulation
Propagation Physics Engine — models how validated branches propagate, compound, decay, or stabilize through the graph over time.
Adds survival probability and stability metrics.
IB
Interpretation Boundary
Output Qualification Gate — applies final interpretation constraints: survival threshold filtering, ranking, and output limits.
Presents results to users.
